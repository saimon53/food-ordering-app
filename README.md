# Food Ordering App

A Flutter-based Food Ordering Application integrated with Firebase.

## Features

- User Registration and Login
- Browse Food Items
- Search Food
- Food Categories
- Add to Cart
- Favorites
- Order History
- Checkout
- Admin Panel
- Firebase Authentication
- Cloud Firestore Database

## Technologies Used

- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore

## Getting Started

This project is built with Flutter.

To run the application:

1. Install Flutter SDK.
2. Clone this repository.
3. Open the project folder in VS Code.
4. Run the following commands:

```bash
flutter pub get
flutter run
```
